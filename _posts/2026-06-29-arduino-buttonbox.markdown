## Concept

### Need 

I play a lot of racing sim games: Assetto Corsa, Dirt Rally, Euro Truck Simulator, and so many more. But more recently, I've gotten into flight sim - especially Microsoft Flight Simulator 2024.
All of these games have numerous controls like parking brake, wipers, ignition, ... (an exhaustive list would take about a page and a half for all systems in an Airbus A320). 

In brief, there's way too many controls and my limited racing and flight sim setup (pictured below) has very few options besides some basic controls like pause, look around, etc. (TODO: add more here). I had an idea to use some existing switches, my Ender 3d Pro, and an Arduino Micro to control.
